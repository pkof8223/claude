강남 나이트라이프 가이드
설계도 먼저 확인해주세요

코드를 만들기 전에, 어떤 화면이 몇 개 생기고 각 화면에 어떤 정보가 저장되는지 먼저 정리했습니다. 여기서 이상한 점이나 빠진 항목을 말씀해주시면 수정한 뒤 2단계(실제 화면 만들기)로 넘어가겠습니다.

⚠ 게재 범위 원칙 반영

업소 등록 화면의 "카테고리" 항목은 클럽 · 칵테일바 · 라운지바 · 루프탑바 · 펍 5개만 선택할 수 있게 만듭니다. 유흥주점은 목록 자체에 없어서 관리자가 실수로도 등록할 수 없습니다.

⚠ 직접 관리 방식 (추가 요청 반영)

관리자 화면의 모든 등록·수정은 버튼과 입력칸으로만 진행됩니다. 배너 이미지도 "파일 첨부" 버튼을 눌러 사진을 올리는 방식이며, HTML이나 코드를 직접 입력하는 화면은 없습니다. 업소·글·배너 전부 동일합니다 — 사진은 첨부, 글자는 입력칸에 타이핑, 날짜는 달력에서 클릭.

A.전체 화면 지도

방문자용 5개 화면 + 관리자용 6개 화면, 총 11개 화면입니다.

B.화면별 상세

각 화면에서 무엇을 보여주고, 어느 언어로 만드는지 정리했습니다.

화면보여줄 내용언어
① 메인 업소 카드 목록(사진·이름·카테고리·지역). 상단 배너 1개, 목록 5·15번째 자리 광고, "추천" 고정 카드. 소개 문구·히어로 없이 목록이 바로 보임 zh-CN
② 업소 상세 사진 갤러리, 영업시간·휴무, 입장료(남/여·요일별), 드레스코드, 여권 지참 여부, 평균예산, 중/한 주소, 택시 기사에게 보여주기 버튼, 구글맵 링크, 위챗/인스타, 하단 배너 zh-CN

이대로 진행해도 될까요?

아래 체크리스트를 보시고 문제없으면 "2단계 진행해줘"라고 말씀해주세요. 그러면 이 설계를 바탕으로 실제 화면(메인·업소상세·가이드·광고문의)을 가짜 데이터로 채워서 브라우저에서 볼 수 있게 만들겠습니다.

  • 화면 11개(방문자 5 + 관리자 6) 구성이 맞는지
  • 업소 정보 항목에 빠진 게 없는지 (예: 추가로 필요한 정보가 있다면 알려주세요)
  • 카테고리 5종(클럽/칵테일바/라운지바/루프탑바/펍) 외 추가할 분류가 있는지
  • 광고 자리 4종(상단배너/목록삽입/상세하단/상단고정) 구성이 맞는지
다음 단계: 2단계 — 프론트 화면(가짜 데이터) → 3단계 관리자 화면 → 4단계 방문자 통계 → 5단계 Cloudflare 배포 순으로 진행하며, 매 단계 확인을 받고 넘어갑니다.
